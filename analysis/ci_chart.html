The honest ranking · MPI with its 95% interval

Each row is a state. The dot is the MPI value; the whisker is OPHI's published 95% interval. In Tableau this is two marks on one dual axis: a Circle at mpi and a Gantt bar that starts at mpi_ci_lo with Size = mpi_ci_hi - mpi_ci_lo. Every adjacent pair overlaps, so there is no defensible "first" or "second" -- only bands.

Tableau recipe. Rows: state. Columns: mpi_ci_lo (Gantt bar; Size = calculated field mpi_ci_hi - mpi_ci_lo; hide its axis heading) and mpi (Circle) → right-click the second MPI pill → Dual Axis, then right-click the axis itself → Synchronize Axis (Tableau adds a warning triangle until you do). Sort state by MPI descending, hide axis headings, colour the circle by mpi_band with the atlas ramp, whisker in light grey.
